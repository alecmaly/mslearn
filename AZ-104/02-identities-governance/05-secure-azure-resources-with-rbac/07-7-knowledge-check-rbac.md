 An administrator needs a report of successful Azure RBAC role-assignment write operations in a specified subscription during the previous seven days. Which approach should they use?

 
 

 
 
 
 
 
 Open the subscription's Activity log, set the timespan to the previous seven days, and filter Operation to Create role assignment (Microsoft.Authorization/roleAssignments/write) and Status to Succeeded.

 

 
 
 
 

 
 
 

 
 
 
 
 At the subscription scope, select Access control (IAM) > Download role assignments.
