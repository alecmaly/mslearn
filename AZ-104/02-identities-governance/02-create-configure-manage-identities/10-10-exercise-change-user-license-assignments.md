- In the left navigation, under Identity, select Users.

- In the Users page, on the menu, select + New user and then Create new user.

## Update user license assignments

License assignment to individual users is managed through the Microsoft 365 admin center.

- Open the Microsoft 365 admin center.

- Select Billing, then select Licenses.

- Select an available license from the list.

- Select Licensed users from the menu near the top of the page.

- Select + Assign licenses.

- Search for and select Dominique Koch, then select Assign at the bottom of the page.

- When complete, verify the license is listed on Dominique Koch's profile in the Microsoft Entra admin center under Identity > Users > select the user > Licenses.
