# Exercise - add groups in Microsoft Entra ID

 
 
 
 Completed
 
 
 

 

 
 
- 2 minutes

 
 

 

 
 Exercise environment needs - this lab assumes you have a basic Microsoft Entra tenant with at least User Administrator rights to complete it. You can get a free trial subscription at Try Microsoft Azure for free.

## Create a Microsoft 365 group in Microsoft Entra ID

- Browse to the Microsoft Entra admin center.

- In the left navigation, under Identity, select Groups.

- In the Groups page, on the menu, select New group.

- Create a group using the following information:

Setting
Value

Group type
Microsoft 365

Group name
Northwest Sales

Membership type
Assigned

Owners
Assign your own administrator account as the group owner

Members
Assign a member of this group

- When complete, verify the group named Northwest sales is shown in the All groups list.

- You have to refresh the All groups a couple of times for the new group to show up.
